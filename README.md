# イセログ 〜異世界文明開拓〜

- `js/core/`  ルール（battle＝戦闘、ai＝敵の動き方、field＝探索）。画面と通信に依存しません
- `js/ui/`    画面（view＝描画エンジン、battleview＝戦場、fieldview＝フィールド、input、audio、main）
